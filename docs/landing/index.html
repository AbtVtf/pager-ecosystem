Apps for your pocket.

A pocket-sized device that gives anyone, anywhere, access to a universe of small, useful apps — over the internet when available, over LoRa mesh when not.

Status: pre-alpha. Open-source. Apache 2.0 (TBD).

Reach

Wi-Fi where it's available. Multi-hop LoRa mesh where it isn't. One identity, same apps, both transports.

Snappy

Apps render in < 100 ms once on-screen. Frames are tiny CBOR. The wire format respects the device's actual constraints.

Open

Anyone can publish an app. Anyone can run an Exit Node. Anyone can fork the firmware. No fees, no gatekeepers.

Get a device

PagerOS targets the LILYGO T-LoRa Pager (ESP32-S3, 480 × 222 IPS screen, QWERTY keyboard, SX1262 LoRa, GPS, NFC). That hardware is available directly from LILYGO. We do not sell or resell devices; we publish the firmware that runs on yours.

  • Buy the hardware from LILYGO and flash PagerOS firmware with pagerctl flash. See the first-boot guide.
  • Already have one running Meshtastic? Dual-boot is supported; the two firmwares share the device but not the air.
  • No device yet? The desktop simulator renders apps pixel-accurate to the real screen so you can try the ecosystem before buying.

Build an app

Writing a PagerOS app is closer to writing a web handler than to writing firmware. "Hello world" is under 20 lines in Python. Apps run on your own server; the device renders what you return. 

from pageros import App, Screen, Text

app = App(name="Hello", lora_compatible=True)

@app.screen("/")
def home(ctx):
    return Screen(title="Hello", body=[Text(s="Hi from PagerOS.")])

if __name__ == "__main__":
    app.run(port=8080)

Publish to the Marketplace with pagerctl publish, or sideload by URL from any device. See the developer guide to start.
